# Reglas de componentes Villaverde

- Usa Cormorant Garamond para títulos comerciales y DM Sans para interfaz y lectura.
- Reserva el rosa para la acción principal. Usa esmeralda para beneficios o confirmaciones y dorado para detalles premium.
- Cada bloque comercial debe responder: qué incluye, cuánto cuesta, para quién conviene y cuál es el siguiente paso.
- El CTA principal debe describir la acción: “Cotizar por WhatsApp” o “Consultar fecha”.
- Mantén controles táctiles de al menos 44 px, foco visible, contraste AA y soporte para movimiento reducido.
- Toda condición de compra debe conservar: “La cotización no reserva la fecha” y “Reserva con contrato y $3,000 de anticipo”.
- La ruta /ui es una referencia de desarrollo y devuelve 404 en producción.
